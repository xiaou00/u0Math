#代数几何 

在[[层]]的定义中, 我们给出了下面这个图表, 我们一般要求他是正合的.

```tikz
\usepackage{tikz-cd}
\begin{document}
\large
\begin{tikzcd}[cramped]
	0 && {\mathcal{F}(U)} && {\prod_i\mathcal{F}(U_i)} && {\prod_{i,j}{\mathcal F(U_i\cap U_j)}}
	\arrow[from=1-1, to=1-3]
	\arrow["{e:t\mapsto(\mathrm{res}_{U,U_i}(t))_{i\in I}}"', from=1-3, to=1-5]
	\arrow["{p:(t_i)_{i\in I}\mapsto(\mathrm{res}_{U_i,U_i\cap U_j}(t_i))_{i,j\in I}}", bend left=30, from=1-5, to=1-7]
	\arrow["{q:(t_i)_{i\in I}\mapsto(\mathrm{res}_{U_j,U_i\cap U_j}(t_j))_{i,j\in I}}"', bend right=30, from=1-5, to=1-7]
\end{tikzcd}
\end{document}
```

其中 $e$ 是平行对 $p,q$ 的[[等值子]].

- **局部公理** 由 $e$ 的单性保证.
- **粘结公理** 由 $e$ 的等化子性质保证.

我们若对此稍作改写, 若要求层的靶范畴是[[Abel范畴]], 我们可以作 $p-q$. 即

```tikz
\usepackage{tikz-cd}
\begin{document}
\large
\begin{tikzcd}[cramped]
	0 && {\mathcal{F}(U)} && {\prod_i\mathcal{F}(U_i)} && {\prod_{i,j}{\mathcal F(U_i\cap U_j)}}
	\arrow[from=1-1, to=1-3]
	\arrow[from=1-3, to=1-5]
	\arrow["{{e:t\mapsto(\mathrm{res}_{U,U_i}(t))_{i\in I}}}"', shift right=3, draw=none, from=1-3, to=1-5]
	\arrow[from=1-5, to=1-7]
	\arrow["{{p-q:(t_i)_{i\in I}\mapsto(\mathrm{res}_{U_i,U_i\cap U_j}(t_i)-\mathrm{res}_{U_j,U_i\cap U_j}(t_j))_{i,j\in I}}}", shift left=3, draw=none, from=1-5, to=1-7]
\end{tikzcd}
\end{document}
```

那么这就构成一个正合列. 此时 $e$ 是 $\ker(p-q)$. 回忆[[仿射概形拟凝聚层的Čech复形]], 它也只是这个定义的一种特殊情形.

>[!question] 问题1
>怎么将芽上的局部信息提升到宏观层面?

>[!solution]
>我们可以对于区域 $U$ 中的芽 $s_y\in\mc F_y$, 每个都选取充分小的邻域 $V_y$ 和一个截面 $t^y\in\mc F(V_y)$, 再应用粘结公理.
