#代数几何 

一个非常简明的[[概形]]而非[[仿射概形]]的例子就是去掉原点的仿射平面.

设 $\mathbb A^2=\Spec \mathbb k[x,y]$ 为仿射平面, 零点所对应的理想是 $(x,y)$. 于是我们可以定义 $\mathbb A^{2,*}=\mathbb A^2\setminus\set{[(x,y)]}$, 显然这是开子空间 (因为单点的Zariski闭包是自己从而是闭的, 理想的极大性). 从而是开子概形, 定义如下:

```python
k.<x,y>=QQ[] # 二元多项式环 (取Q)
Aff=AffineSpace(k) # 对应的仿射概形
Origin=Aff.subscheme([x,y]) # 原点理想 (x,y)
Sch=Origin.complement() # 原点的补集
print(Sch) # 原点的补集对应的子概形 
```

虽然他并不是标准开集, 但他是两个标准开集的并集: 
$$\mathbb A^{2,*}=D(x)\cup D(y)$$
通过下面的代码也能验证其非仿射概形:

```python
try:
    print(Sch.coordinate_ring()) # 原点的补集的坐标环
except AttributeError:
    print("Not Affine Scheme") # 原点的补集不是仿射概形, 因此没有坐标环
```

我们也可以证明他不是仿射概形, 证明的关键在于 $V(x)\cap V(y)=\O$.
